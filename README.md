# HC Manager

Tablero de HC y gestión de horarios para Operaciones.

## ¿Qué hace?

- Altas, ediciones y bajas con fecha (inmediatas o programadas).
- Transferencias entre campañas y canales con fecha efectiva.
- Historial completo de cambios por agente.
- Métricas de HC activo, altas, bajas y attrition por periodo.
- Importación CSV/XLSX y exportación a CSV.

## Ejecutar localmente

```bash
pip install -r requirements.txt
python hc_manager.py
